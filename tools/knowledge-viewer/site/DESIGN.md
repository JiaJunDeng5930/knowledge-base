# 知识库阅读器

## 连续阅读打磨

本轮只改人类阅读表面，不改查询、知识数据或 FSRS 语义。参考站的启发是让链接延续思考，而不是把每次点击变成一次重新找路。保留有序森林和独立的记忆对象，不把自然语言 bullet 强制解释成「标题 + 正文」。只有显式 Markdown 标题或简短标签才提升为标题，其余原文完整排版，不截断、不重复。

桌面阅读路径仍为有序并排书页；已越过的书页留出可点击的窄书脊，当前来源链接有静态标记。窄屏一页一屏，前后篇均有显式按钮。专注阅读仅隐藏其他书页，不删除路径。全局导航可换入口，浏览器后退恢复原路径；不占用浏览器原生 Alt + 左右快捷键。

每个路径前缀拥有独立的设备内阅读视图：滚动位置、展开项、筛选、结果数量。前缀未变则不重置，回退重访同一前缀则恢复；刷新知识数据不清空视图。只在会话内保存视图，不将私有正文写入浏览器存储。URL 可携带「在父级中定位某条 bullet」的目标，目标必须属于当前子树，否则明确提示。定位自动展开祖先并滚动到原文；普通打开已有页只激活，不改变已有展开状态。

正文中的子节点默认连续展开，目录跳转用于长篇定位；关系信息放到所选笔记之后，空关系组不占位置。记忆关联以 cue 区分，调度参数降为按需查看；不能让数据库编号成为主要识别方式。搜索与列表不重复标题和同一段摘要，提供父级上下文与命中数量；在上下文中打开可直接定位原位置。

验证重点为原文完整性、定位地址往返、重复目标与分支替换规则、有序子树、会话视图恢复、构建与只读边界。当前请求没有要求浏览器测试，按 Sites 环境约束不启动浏览器 QA；不把静态及程序检查称为真实浏览器验收。

本次重写以连续阅读和探索知识关联为主要活动。以 Andy Matuschak 的 working notes 为参考，采用白色书页、蓝色文本链接、独立滚动的并排笔记；窄屏一次阅读一篇，通过顶部阅读路径返回前文。没有装饰图片、动画或营销首页。

目录列保留整个有序森林的入口。主题索引、全部笔记、有效标签、全文搜索和 FSRS 对象索引覆盖不同定位方式，搜索结果带祖先上下文。正文保留数据库原文；允许安全的 Markdown 排版并提供原文视图。层级子节点可折叠或作为独立笔记打开。直接引用、反向引用与记忆关联分别展示，不能把父子关系当成引用，也不能把一个 bullet 当成一张复习卡。

阅读路径由 URL 中的有序面板描述唯一确定。关联在当前面板右侧打开，替换它之后的分支，前面的阅读位置保持；已有面板的再次打开定位到该面板。浏览器后退、前进、刷新和复制地址保留阅读路径。面板折叠仅属于显示状态，不更改知识。快捷键和提示不承担唯一入口。

沿用原查看器的七个固定 GET 查询与数据契约：bullet、bullet_reference、effective_bullet_tag、scheduler_config、fsrs、fsrs_bullet、fsrs_review。根据当前仓库的权威 schema，补齐旧查看器遗漏的 fsrs.cue，用于显示具体的复习线索与检索对象。Supabase 凭据仅在 Worker 服务端环境中使用，浏览器只取得快照。bigint 在 Data API 转为十进制字符串。分页到空页；任一查询失败整次刷新失败，保留上一份可读内容并明确错误，不展示半份快照。各表由独立 REST 请求读取，刷新期间数据库并发变更可能造成短暂不一致；不声称是事务快照。

部署在仅所有者可访问的 ChatGPT Site。该发布使用独立的 Sites 源码仓库，本目录将已部署源码同步到 GitHub；不修改数据库权限或 schema。原项目 server.py 的固定只读能力迁移到 Worker，原模型排序与关联语义保留。

验收覆盖长正文、任意层级、bigint、双向引用、共享 Scheduler 和 FSRS 多对多关系；读取真实 Supabase 数据并校验结果数量。检查搜索、路径还原、分页和失败语义，执行完整生产构建。这里不提供编辑知识、评分或修改调度能力。

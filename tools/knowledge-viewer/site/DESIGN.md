# 知识库阅读器

## Bullet 预览与批注

Supabase 的唯一当前草稿保存固定正式快照 `base`、最新 `proposed` 与累计已处理批注 ID。agent 直接使用 Supabase SQL 工具维护；网站只读取。草稿 RLS 校验服务端专用读取凭据，公共 Supabase key 无法单独读取；凭据错误明确报错，避免被误认为草稿已删除。D1 保存用户在网站上对一条或多条 bullet 写下的批注，agent 使用 Sites 数据库读取工具取得意见。处理意见时在同一 Supabase 更新中保存草稿与已处理 ID，网站随后精确删除对应 D1 行。清理可以重试，读取失败保留旧视图；未完成意见继续显示。日常修改不涉及代码发布。

`lib/bullet-review.ts` 定义传输数据、集合差异和预览快照。`components/bullet-review-context.tsx` 保存读取状态、多选与批注交互。呈现集中在 `reader-presentation/bullet-review.tsx` 和同名 CSS；页内内容块模型保留删除的原文，并为移动或排序变化插入原位置。正文同时显示固定原文和最新拟提交内容，标签和引用显示前后集合，不累积中间版本。选中多个 bullet 后一条意见关联全部选中 ID。

预览范围包括 bullet 正文、结构、直接标签和引用，FSRS 使用正式快照。最终提交只由 agent 在用户确认当前整体 diff 后执行；网站没有正文编辑和正式提交入口。提交校验正式内容仍等于基线，整批变更与草稿删除在同一事务内完成。预览 schema 独立于核心知识定义，不对草稿或批注记录版本历史。

以下各节保留既有阅读设计；其中原有“只读”边界适用于正式知识与 FSRS，网站新增的写入仅限 D1 批注。

## 页内内容块与引用

`components/reader-presentation/page-content/` 独立承载页内呈现：`model.ts` 把有序子树和两个方向的直接引用转换为内容块及来源分组，`block-list.tsx` 共用圆点、折叠和正文，`reference-list.tsx` 展示来源上下文，`content.tsx` 统一 Markdown 与页内链接，`page-content.css` 统一这些表面的排版。所有视觉值继续属于阅读呈现目录；字体、行高和配色沿用 `reader.css` 的公共变量。

参考 Roam 公共帮助图谱，圆点在后文独立打开块，三角只折叠下级，闭合圆环提示隐藏的下级。块标题保持正文语义，不再同时承担另一个打开入口。内部链接使用淡色双括号，外部链接保留新标签页提示。引用与反向引用共用完整原文块，按直接父级上下文分组，路径可以回到祖先并定位原文；不推断未保存的文本提及或引用位置。引用分组默认展开，引用块的下级按需展开，不递归跟随引用边。

正文的折叠与定位沿用原有视图状态；引用实例使用独立的状态键，不干扰正文折叠、页内搜索命中或定位节点。重访页面恢复二者的状态。删除笔记总数、记忆对象总数、字符数及重复的内容数量；只保留搜索匹配、阅读路径位置等帮助完成当前操作的信息。

## 操作收敛与阅读呈现

本轮以正文和链接作为阅读界面。全局只保留目录、搜索与阅读设置；首页入口只使用站点名称。桌面通过并排书页与书脊回看前文，窄屏和专注状态才显示路径选择与方向键，不再同时摆放顶部标签、可点击标题和底部翻页。页内圆点承担独立打开内容的操作；父级路径本身承担上下文定位，取消重复的「在上下文中看」。保留原有知识索引、搜索、引用、记忆对象、路径恢复、原文、字号和只读能力。

`components/reader-presentation/` 是阅读视觉体验的统一边界：`reader.css` 的 `:root` 集中声明字体、字号比例、行高、颜色、间距、页宽、缩进、书脊、图标、热区和表面效果，其余规则在此文件及页内子模块组合这些值，响应式规则与所属表面相邻。`metrics.ts` 从 CSS 的实际值读取字体设置与书脊偏移；业务组件只传递层级、页序和用户字号，不散落像素尺寸、断点或 SVG 大小。组件库保持原样，由此模块统一覆盖当前阅读表面。

参考站实测英文正文为 17px / 24px、标题为 28px / 34px。中文正文采用 17px / 1.65，段落、列表、引用、预览共用正文行高；界面标签单独使用 1.5。短标签仍使用文字，动作使用标准图标并保留可访问名称和悬停提示。普通 Markdown 换行按文本流排版，显式换行与代码空白保留。

## 连续阅读打磨

本轮只改人类阅读表面，不改查询、知识数据或 FSRS 语义。参考站的启发是让链接延续思考，而不是把每次点击变成一次重新找路。保留有序森林和独立的记忆对象，不把自然语言 bullet 强制解释成「标题 + 正文」。只有显式 Markdown 标题或简短标签才提升为标题，其余原文完整排版，不截断、不重复。

桌面阅读路径仍为有序并排书页；已越过的书页留出可点击的窄书脊，当前来源链接有静态标记。窄屏一页一屏，上方路径选择与方向键可切换前后篇。专注阅读仅隐藏其他书页，不删除路径。全局导航可换入口，浏览器后退恢复原路径；不占用浏览器原生 Alt + 左右快捷键。

每个路径前缀拥有独立的设备内阅读视图：滚动位置、展开项、筛选、结果数量。前缀未变则不重置，回退重访同一前缀则恢复；刷新知识数据不清空视图。只在会话内保存视图，不将私有正文写入浏览器存储。URL 可携带「在父级中定位某条 bullet」的目标，目标必须属于当前子树，否则明确提示。定位自动展开祖先并滚动到原文；普通打开已有页只激活，不改变已有展开状态。

正文中的子节点默认连续展开，目录跳转用于长篇定位；关系信息放到所选笔记之后，空关系组不占位置。记忆关联以 cue 区分，调度参数降为按需查看；不能让数据库编号成为主要识别方式。搜索与列表不重复标题和同一段摘要，提供父级上下文与命中数量；在上下文中打开可直接定位原位置。

验证重点为原文完整性、定位地址往返、重复目标与分支替换规则、有序子树、会话视图恢复、构建与只读边界。当前请求没有要求浏览器测试，按 Sites 环境约束不启动浏览器 QA；不把静态及程序检查称为真实浏览器验收。

本次重写以连续阅读和探索知识关联为主要活动。以 Andy Matuschak 的 working notes 为参考，采用白色书页、蓝色文本链接、独立滚动的并排笔记；窄屏一次阅读一篇，通过顶部阅读路径返回前文。没有装饰图片、动画或营销首页。

目录列保留整个有序森林的入口。主题索引、全部笔记、有效标签、全文搜索和 FSRS 对象索引覆盖不同定位方式，搜索结果带祖先上下文。正文保留数据库原文；允许安全的 Markdown 排版并提供原文视图。层级子节点可折叠或作为独立笔记打开。直接引用、反向引用与记忆关联分别展示，不能把父子关系当成引用，也不能把一个 bullet 当成一张复习卡。

阅读路径由 URL 中的有序面板描述唯一确定。关联在当前面板右侧打开，替换它之后的分支，前面的阅读位置保持；已有面板的再次打开定位到该面板。浏览器后退、前进、刷新和复制地址保留阅读路径。面板折叠仅属于显示状态，不更改知识。快捷键和提示不承担唯一入口。

沿用原查看器的七个固定 GET 查询与数据契约：bullet、bullet_reference、effective_bullet_tag、scheduler_config、fsrs、fsrs_bullet、fsrs_review。根据当前仓库的权威 schema，补齐旧查看器遗漏的 fsrs.cue，用于显示具体的复习线索与检索对象。Supabase 凭据仅在 Worker 服务端环境中使用，浏览器只取得快照。bigint 在 Data API 转为十进制字符串。分页到空页；任一查询失败整次刷新失败，保留上一份可读内容并明确错误，不展示半份快照。各表由独立 REST 请求读取，刷新期间数据库并发变更可能造成短暂不一致；不声称是事务快照。

部署在仅所有者可访问的 ChatGPT Site。该发布使用独立的 Sites 源码仓库，并将完整源码同步到原 GitHub 项目，不修改数据库权限或 schema。原项目 server.py 的固定只读能力迁移到 Worker，原模型排序与关联语义保留。

验收覆盖长正文、任意层级、bigint、双向引用、共享 Scheduler 和 FSRS 多对多关系；读取真实 Supabase 数据并校验结果数量。检查搜索、路径还原、分页和失败语义，执行完整生产构建。这里不提供编辑知识、评分或修改调度能力。
